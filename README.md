# 🛒 Sistema de Inventario y Facturación para Supermercado "EL ÁRABE"

Proyecto final desarrollado en **Python** para el curso de Algoritmos, enfocado en la gestión de inventarios y facturación comercial. Incluye una interfaz gráfica (GUI) e integración de persistencia de datos en archivos planos.

---

## 🛠️ Tecnologías y Requisitos Cumplidos

* **Lenguaje:** Python 3.14
* **Interfaz Gráfica:** Tkinter (`Menu Grafico.py`)
* **Persistencia de Datos:** Archivos de texto plano (`.txt`) en `C:\Archivos\Grupo7`
* **Arquitectura:** Programación modular con subventanas `Toplevel` y manejo de eventos.
* **Credenciales Iniciales por Defecto:**
  * **Usuario:** `Admin`
  * **Contraseña:** `Algoritmos123`

---

## 📂 Archivos del Proyecto

* **`Menu Grafico.py`**: **Archivo principal.** Contiene la interfaz gráfica de usuario (GUI) en Tkinter con el menú del sistema, login y navegación entre módulos.
* **`PROYECTO FINAL FACTURACION1.py`**: Módulo de lógica y estructuras de datos para las operaciones del sistema.
* **`PROYECTO FINAL FACTURACION.py`**: Versión inicial del núcleo de operaciones del proyecto.

---

## 🚀 Módulos del Sistema

Con base en las especificaciones del enunciado, el sistema implementa:

1. 🔐 **Mantenimiento de Usuarios:** Alta, baja, modificación y autenticación.
2. 👥 **Mantenimiento de Clientes:** Registro de clientes (Código, Nombre, Dirección, Teléfono, NIT).
3. 📦 **Mantenimiento de Productos:** Control de stock y consulta por código de producto.
4. 🏷️ **Categoría de Productos:** Clasificación y generación de reportes.
5. 🧾 **Módulo de Facturación:** Emisión de comprobantes, rebaja automática de inventario y consulta correlativa.
